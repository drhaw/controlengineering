Pengenalan: Terjemahan Persamaan ke Gambar Rajah Blok Introduction: Translating Equations to Block Diagrams

Dalam kejuruteraan kawalan, sistem dinamik sering diwakili oleh set persamaan algebra dalam domain-s. Persamaan ini boleh divisualisasikan menggunakan Gambar Rajah Blok melalui tiga elemen asas: In control engineering, dynamic systems are often represented by algebraic equations in the s-domain. These equations can be visualized using Block Diagrams through three basic elements:

1 Simpang PenjumlahSumming Junction

Mewakili operasi tambah (+) atau tolak (-). Cth: X = A - B akan mempunyai simpang bulat dengan A(+) dan B(-).Represents addition (+) or subtraction (-). Ex: X = A - B will have a circular junction with A(+) and B(-).

2 Blok SistemSystem Block

Mewakili pendaraban isyarat dengan Rangkap Pindah (Transfer Function). Cth: Y = G(s)X. Isyarat X masuk ke blok G, lalu Y keluar.Represents signal multiplication by a Transfer Function. Ex: Y = G(s)X. Signal X enters block G, Y exits.

3 Titik AmbilanTakeoff Point

Menyebarkan/mengagihkan isyarat yang sama ke berbilang laluan (biasanya digunakan untuk laluan suap balik / feedback).Distributes the identical signal to multiple paths (commonly used for feedback loops).

E(s) = R(s) - H1(s)C(s)

Langkah 1 / 3Step 1 / 3
Persamaan 1: E(s) = R(s) - H₁(s)C(s). Mulakan dengan Simpang Penjumlah. Lukis input R(s) dan isyarat perantaraan E(s). Abaikan H₁ dahulu.Equation 1: E(s) = R(s) - H₁(s)C(s). Start with the Summing Junction. Draw input R(s) and intermediate signal E(s). Ignore H₁ for now.
Persamaan 2: C(s) = G₁(s)E(s). Masukkan isyarat E(s) ke dalam blok G₁(s) untuk menghasilkan output C(s).Equation 2: C(s) = G₁(s)E(s). Feed signal E(s) into block G₁(s) to produce output C(s).
Lengkapkan Suap Balik (Feedback): Ambil isyarat C(s), lalui blok H₁(s), dan sambung ke Simpang Penjumlah dengan tanda negatif (-).Complete Feedback: Take signal C(s), pass it through block H₁(s), and connect to the Summing Junction with a negative (-) sign.

Soalan 2Question 2 SederhanaMedium

Langkah 1 / 4Step 1 / 4

Persamaan 2: Y(s) = G₁(s)X(s). Isyarat X(s) melalui blok G₁ menjadi isyarat Y(s).Equation 2: Y(s) = G₁(s)X(s). Signal X(s) passes through block G₁ to become Y(s).
Persamaan 3: C(s) = G₂(s)Y(s). Isyarat Y(s) melalui blok G₂ menjadi isyarat output akhir C(s).Equation 3: C(s) = G₂(s)Y(s). Signal Y(s) passes through block G₂ to become final output C(s).
Lengkapkan Suap Balik: Ambil C(s) terus ke Simpang Penjumlah dengan tanda (-). Ini dipanggil 'Unity Feedback'.Complete Feedback: Route C(s) directly to the Junction with a (-) sign. This is Unity Feedback.

Soalan 3Question 3 Sederhana (Gangguan)Medium (Disturbance)

E(s) = R(s) - H1(s)C(s)
X(s) = G1(s)E(s) + D(s)
C(s) = G2(s)X(s)
Langkah 1 / 4Step 1 / 4
Persamaan 1: E(s) = R(s) - H₁(s)C(s). Lukis Simpang 1 dengan input R(s) dan isyarat E(s).Equation 1: E(s) = R(s) - H₁(s)C(s). Draw Junction 1 with R(s) input and E(s) signal.
Persamaan 2: X(s) = G₁(s)E(s) + D(s). Lukis blok G₁, kemudian tambah Simpang 2 untuk memasukkan gangguan D(s) dengan tanda (+). Outputnya ialah X(s).Equation 2: X(s) = G₁(s)E(s) + D(s). Add G₁, then Junction 2 to insert disturbance D(s) (+). Output is X(s).
Persamaan 3: C(s) = G₂(s)X(s). Isyarat X(s) melalui blok G₂ menjadi output C(s).Equation 3: C(s) = G₂(s)X(s). Signal X(s) passes block G₂ to become C(s).
Lengkapkan Suap Balik: Ambil C(s) lalu blok H₁ dan masuk ke Simpang 1 dengan tanda (-).Complete Feedback: Route C(s) through H₁ into Junction 1 with a (-) sign.

Soalan 4Question 4 Sukar (Laluan Selari)Hard (Parallel)

X1(s) = R(s) - H1(s)C(s)
X2(s) = G1(s)X1(s)
X3(s) = G2(s)X1(s)
C(s) = X2(s) + X3(s)
Langkah 1 / 4Step 1 / 4
Persamaan 1: X₁(s) = R(s) - H₁(s)C(s). Lukis Simpang Penjumlah awal dengan isyarat keluaran X₁(s).Equation 1: X₁(s) = R(s) - H₁(s)C(s). Draw initial Junction with output signal X₁(s).
Persamaan 2 & 3: Isyarat X₁(s) dipecahkan kepada dua laluan selari (atas: G₁, bawah: G₂) untuk membentuk X₂(s) dan X₃(s).Equations 2 & 3: Signal X₁(s) splits into two parallel paths (top: G₁, bottom: G₂) to form X₂(s) and X₃(s).
Persamaan 4: C(s) = X₂(s) + X₃(s). Gabungkan laluan X₂ dan X₃ ke dalam Simpang Penjumlah baru (+) untuk mendapat C(s).Equation 4: C(s) = X₂(s) + X₃(s). Combine paths X₂ and X₃ into a new Summing Junction (+) to get C(s).
Lengkapkan Suap Balik: Ambil C(s) melalui H₁ dan kembalikan ke Simpang Penjumlah pertama dengan tanda (-).Complete Feedback: Take C(s) through H₁ back to the first Junction with a (-) sign.
